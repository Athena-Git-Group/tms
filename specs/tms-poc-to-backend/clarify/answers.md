# Clarify Answers（使用者拍板，2026-10-19）

由 flow 於 spec gate PASS 後向使用者提問取得，供 plan 與後續 stage 讀取。

## Q1：本次 flow run 的 build 範圍

**答：只做 P1 核心骨幹**——故事 1–6 ＋ 全域規則（GR）：資料模型 migration、核心派工迴圈、認證/授權。P2（營運閉環：故事 7–11、16）與 P3（周邊協作：故事 12–15）不在本次 run 範圍，之後各跑一次 flow。

## Q2：儀表板「平均回應分鐘」的起訖點（gherkin/10 @待釐清 第 1 題）

**答：兩個都要**——儀表板同時顯示兩個指標：
- 平均認領時間：工單建立 → 被認領
- 平均完成時間：工單建立 → 完成

## Q3：儀表板「可賣房數」的定義（gherkin/10 @待釐清 第 2 題）

**答：已查房通過的空房**——房務狀態為 `inspected` 且目前沒有住客的房間數（排除住人中的房）。

> 註：Q2/Q3 屬儀表板投影計算，若儀表板統計不在 P1 範圍內，本答案由後續 P2/P3 run 的 plan 讀取落實。
