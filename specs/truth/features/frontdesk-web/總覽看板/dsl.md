# 總覽看板 DSL（櫃檯 Web）

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

總覽看板：8 個欄與看板範圍、數量卡與欄頭、卡片上的文字、等待膠囊與逾時、數量卡篩選與房號搜尋與泳道、拖曳派單，以及載入中與讀取失敗。資料來自 `getDeskBoard` 一次讀取，數量卡、欄頭、未結案張數都由畫面從這一份算；等待的分鐘數用後端時間校正後的「現在」減去起算時刻、無條件捨去。顏色的說法：灰色（一般）、橘色、紅色、綠色，對應 ui-plan 的四組底色與字色，以元素的語意標記判斷，不比對色碼。拖曳以真實的指標事件進行：滑鼠是按住並移動，觸控是按住約 0.25 秒再移動。

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |

| `"{員工}" 點控制列的篩選膠囊` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：點看板控制列上那顆篩選膠囊。 |

| `"{員工}" 按住 "{房號}" 的卡片開始拖` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：在該房的卡片上按住並拖離原位，不放開。`等待條件`：拖放區出現。案例結束時放開在原位。 |
| `"{員工}" 拖著 "{房號}" 的卡片滑到 "{拖放區}" 上，還沒放開` | `員工`：字串。<br>`房號`：字串。<br>`拖放區`：字串。 | 不支援 | 無 | `頁面操作`：按住卡片拖到該拖放區上方停住。 |
| `"{員工}" 把 "{房號}" 的卡片拖到 "{拖放區}" 放開` | `員工`：字串。<br>`房號`：字串。<br>`拖放區`：字串。 | 不支援 | 無 | `頁面操作`：按住卡片、拖到該拖放區、放開；「待認領」欄不在視窗內時把卡片拖向看板邊緣讓看板自動捲動。`等待條件`：`deskAssignTask` 的請求結束（成功、被拒或斷線）與畫面變化。`回寫資料`：請求內容（`dept`、`via`）與回應。 |
| `"{員工}" 拖著 "{房號}" 的卡片在拖放區以外的地方放開` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：按住卡片拖到看板上兩個拖放區以外的位置放開。 |
| `"{員工}" 試著拖 "{房號}" 的卡片` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：在該卡片上做與拖待派單卡片相同的手勢（按住並移動；觸控是按住再移動）後放開。 |
| `過了 {秒數} 秒，"{員工}" 沒有按任何東西` | `秒數`：整數。<br>`員工`：字串。 | 不支援 | 無 | `頁面操作`：把瀏覽器時鐘往後推該秒數，不操作畫面。`等待條件`：自動再試的讀取結束。 |
