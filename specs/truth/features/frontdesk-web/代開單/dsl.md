# 代開單 DSL（櫃檯 Web）

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

代開單面板：住客打電話要東西或報修時，櫃檯人員從工具列的「代開單」叫出面板，打房號、點常用品項、打其他需求，一次送出開好單，單直接進房務或工務的待認領，不經待派單。面板打開時讀一次房間清單（`listDeskRooms`），房號是否有效、建議房號、住客卡、空房提示都由畫面從這一份算；類似單提醒用看板資料（`getDeskBoard` 的卡片，含 `menuKey`）在畫面上算；送出是 `deskCreateRequests`（必帶 `Idempotency-Key`；內容沒改就重用同一把，收到 4xx 或內容改了就換一把）。面板外觀是 iPadOS 26：左上一顆無障礙名稱「取消」的 ✕ 圓鈕，面板外是暗色遮罩（無障礙名稱「關閉」），送出鈕固定在面板底部。

**常用品項**（順序就是面板上的順序；品項鍵就是中文品名，與 contracts 的 `DeskMenuKey` 相同）：

| 品項 | 部門 | 上限 | 開出的單的標題 |
| --- | --- | --- | --- |
| 毛巾、浴巾、礦泉水、拖鞋、牙刷組 | 房務 | 9 | 「{品名} ×{份數}」 |
| 嬰兒床、加床 | 房務 | 2 | 「{品名} ×{份數}」 |
| 冰塊 | 房務 | 2 | 「冰塊 ×{份數} 桶」 |
| 冷氣、熱水、燈具、電視 | 工務 | 1 | 「{品名}有問題」（工務單） |

**送出摘要的組法**：「會開 {n} 張單：{房務清單} 給房務；{工務清單} 給工務。直接進部門待認領，不經派單。」只有一個部門時只有那一段、沒有「；」。房務清單是房務品項依品項順序的「{品名} ×{份數}」（冰塊也不帶「桶」），給房務的其他需求寫「其他需求」排在最後；工務清單是工務品項的品名，給工務的其他需求同樣寫「其他需求」排在最後；清單內以「、」分隔。n 是選了的品項數加上其他需求（有字時算一張）。

**房號有效**：房間清單裡有這個房號。房間清單裡有住客的房，在住住客的資料照後端原樣（姓名含稱謂）。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `飯店的客房與現在的住客如下：` | 無 | 支援：`房號`（必填，字串）、`住客`（選填，字串；姓名照訂房原樣含稱謂，留空代表空房）、`VIP`（選填，是或否）、`入住日`、`退房日`（選填，字串 `M/D`） | `VIP`：否。<br>`入住日`：今天。<br>`退房日`：明天。 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：確保每一列的房號是飯店的客房；住客有填時在訂房副本建立一筆涵蓋現在的在住訂房（照填的姓名、VIP、日期），留空時讓這間房沒有在住的訂房；寫在 `全館有以下的單：` 之後時，表格列出的房間以這裡為準，取代原本的在住訂房。表格沒列、也沒有被 `全館有以下的單：` 放入住客的客房，現在都沒有住客。 |
| `飯店沒有 "{房號}" 這間房` | `房號`：字串。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：確認房間主檔沒有這個房號（有就移除）。 |
| `"{員工}" 已打開代開單面板` | `員工`：字串。 | 不支援 | 無 | `Arrange 來源`：還沒登入時先以該員工登入並開啟總覽看板（已停在某一頁就留在那一頁）。`頁面操作`：按工具列的「代開單」。`等待條件`：面板出現、房間清單讀完（建議房號不是骨架）。 |
| `"{員工}" 已打開代開單面板，房號是 "{房號}"` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：同上，再在房號欄打該房號。`等待條件`：住客卡、空房提示或什麼都不顯示的判斷已畫完。 |
| `"{員工}" 已打開代開單面板，房號是 "{房號}"，選了以下品項：` | `員工`：字串。<br>`房號`：字串。 | 支援：`品項`（必填，字串）、`數量`（選填，整數） | `數量`：1。 | `頁面操作`：同上，再依表格順序在每個品項的格子點該數量的次數。`等待條件`：送出鈕的文字已反映張數。 |
| `"{員工}" 已打開代開單面板，還沒打房號，選了以下品項：` | `員工`：字串。 | 支援：`品項`（必填，字串）、`數量`（選填，整數） | `數量`：1。 | `頁面操作`：打開面板，房號欄留空，依表格點品項。 |
| `代開單面板的其他需求是 "{內容}"，要給 "{部門}"` | `內容`：字串。<br>`部門`：字串；房務、工務。 | 不支援 | 無 | `頁面操作`：在已打開的面板的其他需求打該文字，「這段要給」選該部門。 |
| `"{員工}" 已按 "{按鈕}"` | `員工`：字串。<br>`按鈕`：字串。 | 不支援 | 無 | `頁面操作`：同介面根的 When `"{員工}" 按 "{按鈕}"`，當作 Arrange。`等待條件`：這一下引發的畫面變化結束。 |
| `"{員工}" 已點代開單面板外面的暗色區域` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：同 When `"{員工}" 點代開單面板外面的暗色區域`，當作 Arrange。`等待條件`：面板關閉。 |
| `"{員工}" 剛代開了 "{房號}" 的以下單：` | `員工`：字串。<br>`房號`：字串。 | 支援：`品項`（必填，字串；品項或「其他需求」）、`數量`（選填，整數）、`內容`（選填，字串；其他需求的文字）、`給`（選填，字串；房務、工務） | `數量`：1。<br>`給`：房務。 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：以該員工的身分在後端呼叫 `deskCreateRequests` 並確認成功；還沒登入時再以該員工登入並開啟總覽看板，等這幾張卡片出現在「待認領」欄。 |
| `"{房號}" 這個房號在面板打開之後被從飯店的房間清單移除` | `房號`：字串。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：面板已讀過房間清單之後，在後端把這間房從房間主檔移除；畫面上的房間清單不重讀。 |
| `"{員工}" 的帳號在面板打開之後被改成不能代開單的角色` | `員工`：字串。 | 不支援 | 改成房務（`housekeeping`）。 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：在後端把這個帳號的角色改成房務；這個分頁的登入憑證不動（後端每次請求都依帳號目前的角色判斷）。 |
| `"{員工}" 的登入在面板打開之後逾時` | `員工`：字串。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：讓這個分頁的登入憑證在後端失效，下一個請求回 401 `unauthorized`。 |
| `開 "{標題}" 這張單時後端會出錯` | `標題`：字串。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：在資料庫暫時裝一個觸發器，寫入標題等於該文字的任務時丟出錯誤（`specs/truth/techstack.md` 送出失敗的模擬）；案例結束時拆掉。後端回 5xx。 |
| `接下來的代開單送出會被後端判定內容不符合規定` | 無 | 不支援 | 無 | `使用 fixture`：網路攔截。`Arrange 來源`：讓這個分頁接下來的 `deskCreateRequests` 不到達後端，直接得到 422、`Error.code`=`validation_failed`、`details` 有一筆的回應（形狀照 contracts `Error`）。畫面上能送出的內容後端本來都收，這一句只用來驗畫面對這種回應的處理。 |
| `"{員工}" 剛才按送出時網路中斷，「沒有送出」的提示開著` | `員工`：字串。 | 不支援 | 無 | `使用 fixture`：網路攔截。`Arrange 來源`：在已填好的面板上，讓 `deskCreateRequests` 的請求在送出時斷線，按送出鈕。`等待條件`：「沒有送出」的提示出現。之後的請求不再攔截。`回寫資料`：按送出之前面板上的內容（房號、每個品項的份數、其他需求的文字與部門）與這次用的 `Idempotency-Key`。 |
| `"{員工}" 剛才按送出時網路中斷，已按「好」關掉提示，網路已經恢復` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：同上一句，再按提示上的「好」。`等待條件`：提示關閉。 |
| `"{員工}" 剛才按送出時沒有收到回應，但這次的單其實已經開好，已按「好」關掉提示` | `員工`：字串。 | 不支援 | 無 | `使用 fixture`：網路攔截。`Arrange 來源`：在已填好的面板上，讓 `deskCreateRequests` 的請求照常到達後端、後端開好單之後，把回應丟掉（Playwright `route.fetch()` 後中斷）；按送出鈕，等「沒有送出」的提示出現再按「好」。之後的請求不再攔截。`回寫資料`：同上；後端這次開出的單。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `"{員工}" 在房號欄依序打 "{字元}"` | `員工`：字串。<br>`字元`：字串；照順序一個字元一個字元打，可以有字母與全形數字。 | 不支援 | 無 | `頁面操作`：在房號欄目前的內容後面，用鍵盤逐字輸入每一個字元（觸控設定下用螢幕鍵盤的輸入方式）。`等待條件`：每打一個字元房號欄都更新完。 |
| `"{員工}" 在房號欄輸入 "{房號}"` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：清掉房號欄再逐字輸入該房號。`等待條件`：住客卡、空房提示或建議已依新的房號畫完。 |
| `"{員工}" 刪掉房號欄的最後一碼` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：在房號欄按一次刪除鍵。 |
| `"{員工}" 點建議房號 "{房號}"` | `員工`：字串。<br>`房號`：字串。 | 不支援 | 無 | `頁面操作`：在房號欄底下的建議裡，點房號是該房號的那一顆。 |
| `"{員工}" 依序點以下品項：` | `員工`：字串。 | 支援：`品項`（必填，字串）、`次數`（選填，整數） | `次數`：1。 | `頁面操作`：依表格順序，在每個品項的格子上點該次數（觸控設定下用點觸）。`等待條件`：徽章、摘要與送出鈕都更新完。 |
| `"{員工}" 按品項 "{品項}" 底下的 "{鈕}" {次數} 次` | `員工`：字串。<br>`品項`：字串。<br>`鈕`：字串；−、+、移除。<br>`次數`：整數。 | 不支援 | 無 | `頁面操作`：在該品項格子底下那一列按那顆鈕該次數。 |
| `"{員工}" 在其他需求打 "{內容}"` | `員工`：字串。<br>`內容`：字串；照字面，含前後空白。 | 不支援 | 無 | `頁面操作`：清掉其他需求的文字框再逐字輸入。`等待條件`：「這段要給」、類似單提醒、摘要與送出鈕都更新完。 |
| `"{員工}" 在其他需求只打了幾個空白` | `員工`：字串。 | 不支援 | 3 個半形空白。 | `頁面操作`：在空的其他需求文字框輸入空白。 |
| `"{員工}" 在其他需求連續打 {字數} 個字，再貼上 {貼上字數} 個字` | `員工`：字串。<br>`字數`：整數。<br>`貼上字數`：整數。 | 不支援 | 打的與貼上的都是測試自編、不含空白的中文字。 | `頁面操作`：在空的文字框逐字輸入該字數，再用剪貼簿貼上另一段該字數的文字。`回寫資料`：逐字輸入的那一段。 |
| `"{員工}" 清空其他需求` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：把其他需求文字框的字全部刪掉。 |
| `"{員工}" 把其他需求改給 "{部門}"` | `員工`：字串。<br>`部門`：字串；房務、工務。 | 不支援 | 無 | `頁面操作`：在「這段要給」的分段選擇點該部門。 |
| `"{員工}" 按代開單面板的送出鈕` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：按面板底部的送出鈕（不論介面語言、不論上面寫幾張）。`等待條件`：`deskCreateRequests` 的請求結束與畫面變化。 |
| `"{員工}" 點代開單面板外面的暗色區域` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：點面板外的遮罩（不是底下的看板或詳情面板）。 |
| `"{員工}" 按 "{按鈕}"，在還沒有結果之前又連按 {次數} 次` | `員工`：字串。<br>`按鈕`：字串；送出鈕的文字。<br>`次數`：整數。 | 不支援 | 無 | `使用 fixture`：網路攔截。`頁面操作`：讓 `deskCreateRequests` 的回應晚 2 秒才放行，按一下送出鈕，回應回來之前再對同一個位置連點該次數。`等待條件`：回應回來、畫面變化結束。`回寫資料`：這段期間送出的 `deskCreateRequests` 請求數。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `畫面中間打開代開單面板，面板外面是暗色遮罩` | 無 | 不支援 | 無 | `必查`：最上層是一個標題「代開單」的對話框（`aria-modal`），置中；後面有蓋住整個視窗的遮罩，無障礙名稱「關閉」。 |
| `代開單面板左上的關閉鈕名稱是 "{名稱}"` | `名稱`：字串。 | 不支援 | 無 | `必查`：面板標題列左邊有一顆按鈕，它的名稱（文字或無障礙名稱，兩種外觀都算）照字面相符。 |
| `代開單面板由上到下是房號欄、建議房號、"{品項區}"、"{其他需求區}"，送出鈕固定在底部` | `品項區`、`其他需求區`：字串；兩區的區塊標題。 | 不支援 | 無 | `必查`：各區塊都在、上下順序相符，兩個區塊標題照字面相符；送出鈕在面板底部、不在可以捲動的內容裡。 |
| `房號欄是空的，提示字是 "{提示字}"` | `提示字`：字串。 | 不支援 | 無 | `必查`：房號欄的值是空字串，提示字照字面相符。 |
| `房號欄是空的` | 無 | 不支援 | 無 | `必查`：房號欄的值是空字串。 |
| `房號欄是 "{房號}"` | `房號`：字串。 | 不支援 | 無 | `必查`：房號欄的值照字面相符；被濾掉的字元沒有出現在框裡。 |
| `常用品項依序如下，每一格都沒有徽章：` | 無 | 支援：`品名`（必填，字串）、`部門`（必填，字串） | 無 | `必查`：「常用品項」剛好這幾格，左上到右下的順序、每格的品名與部門字相符；每一格都沒有數字徽章、不是選取的樣子。 |
| `12 個品項都是 0` | 無 | 不支援 | 無 | `必查`：12 格都沒有徽章、不是選取的樣子，底下都沒有「−」「+」或「移除」。 |
| `其他需求是空的` | 無 | 不支援 | 無 | `必查`：其他需求文字框的值是空字串；底下沒有「這段要給」。 |
| `代開單面板沒有送出摘要` | 無 | 不支援 | 無 | `必查`：送出鈕上方沒有「會開 … 張單」的摘要。 |
| `送出摘要是 "{摘要}"` | `摘要`：字串。 | 不支援 | 無 | `必查`：送出鈕上方的摘要照字面相符。 |
| `各品項的樣子如下：` | 無 | 支援：`品項`（必填，字串）、`徽章`（選填，字串；留空代表沒有徽章）、`底下`（選填，字串；「−」「{數字}」「+」、「移除」，留空代表沒有） | 無 | `必查`：每一列的品項格子：有徽章時右上角的數字相符、外框是選取的樣子；沒有徽章時不是選取的樣子。格子底下那一列照字面相符（「−」「2」「+」代表減、數量、加三段；「移除」代表一顆滿寬的鈕），留空時沒有那一列。 |
