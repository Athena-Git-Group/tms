# 帳號與登入 DSL（櫃檯 Web）

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

登入頁、設定新密碼畫面、帳號面板、登出、登入狀態跟著分頁，以及介面語言。登入頁向後端送 `staffAccountsLogin`（帶 `client`=`frontdesk_web`），設定新密碼送 `changeOwnPassword`，登入頁的飯店名稱讀 `readPublicHotel`。登入憑證放在分頁自己的儲存空間（關掉分頁就沒有）；介面語言記在這台裝置上、每人一筆，另記一筆登入頁現在的語言。介面語言的說法：繁體中文、英文、日文、越南文；斷言時以該語言的固定字句判斷（登入頁用「登入」鈕的文字，登入後用側欄「總覽看板」的文字）。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `登入頁已經打開` | 無 | 不支援 | 無 | `頁面操作`：以預設飯店的網址開啟登入頁，這個分頁沒有登入。`等待條件`：登入頁畫完。 |
| `登入頁已經打開，介面語言是 "{語言}"` | `語言`：字串。 | 不支援 | 無 | `Arrange 來源`：先把這台裝置記的「登入頁現在的語言」設成該語言，再開啟登入頁。 |
| `登入頁已經打開，員工編號欄已輸入 "{員工編號}"` | `員工編號`：字串。 | 不支援 | 無 | `頁面操作`：開啟登入頁並在「員工編號」輸入該值。 |
| `登入頁已經打開，密碼欄已輸入 "{密碼}"` | `密碼`：字串。 | 不支援 | 無 | `頁面操作`：開啟登入頁並在「密碼」輸入該值，密碼是遮住的。 |
| `登入頁已經打開，密碼欄已輸入 "{密碼}" 並切成明文顯示` | `密碼`：字串。 | 不支援 | 無 | `頁面操作`：同上，再按一次「顯示密碼」。 |
| `登入頁已經打開，忘記密碼的提示開著` | 無 | 不支援 | 無 | `頁面操作`：開啟登入頁並按「忘記密碼？」。`等待條件`：對話框出現。 |
| `"{員工}" 的帳號已連續輸錯密碼 {次數} 次，被鎖定 {分鐘} 分鐘` | `員工`：字串。<br>`次數`：整數。<br>`分鐘`：整數。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：在後端用錯誤密碼登入該次數，帳號進入鎖定。 |
| `"{員工}" 的員工編號是 "{員工編號}"` | `員工`：字串。<br>`員工編號`：字串，照字面，大小寫有分。 | 不支援 | 無 | `使用 fixture`：`BackendChannel`。`Arrange 來源`：在後端把該帳號的員工編號改成該值，密碼與其他欄位不變。本場景之後的句子提到這位員工時，帳號卡與登入憑證都以這個員工編號為準。 |
| `"{員工}" 的帳號已被停用` | `員工`：字串。 | 不支援 | 無 | `Arrange 來源`：在後端把該帳號停用。 |
| `"{員工}" 的密碼是主管給的臨時密碼 "{密碼}"` | `員工`：字串。<br>`密碼`：字串。 | 不支援 | 無 | `Arrange 來源`：在後端把該帳號的密碼設成該值並標記為必須先設定新密碼。 |
| `"{員工}" 已用臨時密碼登入，停在設定新密碼畫面` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：在登入頁用該員工的員工編號與臨時密碼登入。`等待條件`：設定新密碼畫面畫完。`回寫資料`：臨時密碼。 |
| `"{員工}" 已經把臨時密碼改成 "{密碼}"` | `員工`：字串。<br>`密碼`：字串。 | 不支援 | 無 | `Arrange 來源`：在後端以該員工的臨時密碼登入並呼叫 `changeOwnPassword` 改成該值；這個分頁沒有登入。 |
| `"{員工}" 已登入櫃檯畫面，帳號面板開著` | `員工`：字串。 | 不支援 | 無 | `Arrange 來源`：以該員工登入並開啟總覽看板。`頁面操作`：打開側欄、點帳號卡。`等待條件`：帳號面板出現。 |
| `"{員工}" 已登入櫃檯畫面，登出確認提示開著` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：同上，再按「登出」。`等待條件`：確認對話框出現。 |
| `"{員工}" 已登入櫃檯畫面，介面語言是 "{語言}"，登出確認提示開著` | `員工`：字串。<br>`語言`：字串。 | 不支援 | 無 | `Arrange 來源`：先把這台裝置上該員工的介面語言記成該語言，其餘同上一句。 |
| `"{員工}" 已登入櫃檯畫面，語言頁開著` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：登入、打開帳號面板、點「語言」。`等待條件`：語言頁出現。 |
| `"{員工}" 已登入櫃檯畫面，語言頁開著，已經選了 "{選項}"` | `員工`：字串。<br>`選項`：字串。 | 不支援 | 無 | `頁面操作`：同上，再點該選項。 |
| `"{員工}" 已登入櫃檯畫面，"{面板}" 開著` | `員工`：字串。<br>`面板`：字串。 | 不支援 | 全館另有一張待派單的單可供打開。 | `Arrange 來源`：以該員工登入並開啟總覽看板，在後端備一張待派單的單。`頁面操作`：打開該面板（詳情面板、當場回答面板或帳號面板）。 |
| `"{員工}" 已登入櫃檯畫面，另開的新分頁停在登入頁` | `員工`：字串。 | 不支援 | 無 | `使用 fixture`：同一個瀏覽器環境的兩個分頁。`頁面操作`：原本的分頁以該員工登入並停在總覽看板；新分頁開啟櫃檯畫面的網址。之後句型裡的「新分頁」「原本的分頁」分別指這兩個。 |
| `原本的分頁是 "{員工}" 登入、新分頁是 "{同事}" 登入` | `員工`：字串。<br>`同事`：字串。 | 不支援 | 無 | `頁面操作`：兩個分頁各自走登入頁登入。 |
| `"{員工}" 已在總覽看板點了 "{數量卡}" 數量卡、搜尋房號 "{房號}"、把泳道切到 "{泳道}"` | `員工`：字串。<br>`數量卡`：字串。<br>`房號`：字串。<br>`泳道`：字串。 | 不支援 | 無 | `頁面操作`：依序點數量卡、在「搜尋房號」輸入、點泳道分段鈕。`等待條件`：看板依三者重畫。 |
| `這台裝置還沒有任何人選過介面語言，瀏覽器的語言是 "{瀏覽器的語言}"` | `瀏覽器的語言`：字串。 | 不支援 | 無 | `使用 fixture`：瀏覽器設定。`Arrange 來源`：清空這台裝置記的介面語言，以該語系開新的瀏覽器環境。 |
| `這台裝置上各人選過的介面語言如下：` | 無 | 支援：`姓名`（必填，字串）、`選過的語言`（必填，字串；繁體中文、English、日本語、Tiếng Việt） | 無 | `Arrange 來源`：把每一列寫進這台裝置的語言紀錄（每人一筆）；沒有列出的人沒有紀錄。 |
| `"{員工}" 在櫃檯原本那台裝置上選過 "{選項}"` | `員工`：字串。<br>`選項`：字串。 | 不支援 | 無 | `Arrange 來源`：只說明背景，不寫進目前這個瀏覽器環境的語言紀錄。 |
| `上一次的瀏覽器已經關掉，登入頁重新打開` | 無 | 不支援 | 無 | `使用 fixture`：瀏覽器設定。`Arrange 來源`：保留這台裝置的語言紀錄，丟掉所有分頁的登入狀態，重新開啟登入頁。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `有人打開登入頁` | 無 | 不支援 | 無 | `頁面操作`：以預設飯店的網址開啟登入頁。`等待條件`：登入頁畫完，飯店名稱的查詢已有結果。 |
| `有人用飯店識別代碼 "{代碼}" 的網址打開登入頁` | `代碼`：字串。 | 不支援 | 無 | `頁面操作`：以帶該識別代碼的網址開啟登入頁。`等待條件`：`readPublicHotel` 已回應（200 或 404）。 |
| `"{員工}" 在登入頁的 "{欄位}" 輸入 "{內容}"` | `員工`：字串。<br>`欄位`：字串。<br>`內容`：字串。 | 不支援 | 無 | `頁面操作`：在該欄逐字輸入。`等待條件`：無。 |
| `"{員工}" 在登入頁的 "{欄位}" 輸入 {字數} 個字` | `員工`：字串。<br>`欄位`：字串。<br>`字數`：整數。 | 不支援 | 輸入的是英數字。 | `頁面操作`：在該欄逐字輸入該字數的字。 |
| `"{員工}" 在登入頁輸入員工編號 "{員工編號}" 與密碼 "{密碼}" 後按「登入」` | `員工`：字串。<br>`員工編號`：字串。<br>`密碼`：字串。 | 不支援 | 無 | `頁面操作`：照字面輸入兩欄（不轉大小寫、不去空白），按「登入」。`等待條件`：登入請求結束，畫面換頁或出現提示。`回寫資料`：送出的請求內容（`loginId`、`client`）與回應。 |
| `"{員工}" 在新分頁輸入員工編號 "{員工編號}" 與密碼 "{密碼}" 後按「登入」` | `員工`：字串。<br>`員工編號`：字串。<br>`密碼`：字串。 | 不支援 | 無 | 同上一句，操作的是新分頁。 |
| `"{員工}" 打開登入頁右上的語言選單` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：點登入頁右上的語言選單。`等待條件`：選項出現。 |
| `"{員工}" 在登入頁的語言選單選 "{選項}"` | `員工`：字串。<br>`選項`：字串。 | 不支援 | 無 | `頁面操作`：打開語言選單並點該選項。`等待條件`：登入頁的文字換完。 |
| `"{員工}" 直接打開 "{頁}" 的網址` | `員工`：字串。<br>`頁`：字串。 | 不支援 | 無 | `頁面操作`：在同一個分頁直接前往該頁的網址。`等待條件`：換頁結束。 |
| `"{員工}" 輸入新密碼 "{新密碼}"、確認密碼 "{確認密碼}"` | `員工`：字串。<br>`新密碼`：字串。<br>`確認密碼`：字串。 | 不支援 | 無 | `頁面操作`：在設定新密碼畫面的兩欄輸入，不按「更新密碼」。 |
| `"{員工}" 把新密碼設成 "{新密碼}" 並按「更新密碼」` | `員工`：字串。<br>`新密碼`：字串。 | 不支援 | 無 | `頁面操作`：兩欄都輸入該值，按「更新密碼」。`等待條件`：`changeOwnPassword` 的請求結束，畫面換頁或出現提示。 |
| `"{員工}" 重新整理網頁` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：重新載入這個分頁。`等待條件`：畫面畫完、資料載入完成。 |
| `"{員工}" 點側欄的帳號卡` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：側欄收起時先打開，再點底部的帳號卡。`等待條件`：帳號面板出現。 |
| `"{員工}" 點身分卡` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：點帳號面板的身分卡。 |
| `"{員工}" 在登出確認提示按「登出」` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：按確認對話框裡的「登出」。`等待條件`：登入頁畫完。 |
| `"{員工}" 在語言頁選 "{選項}"` | `員工`：字串。<br>`選項`：字串。 | 不支援 | 無 | `頁面操作`：點語言頁的該選項。`等待條件`：畫面文字換完。 |
| `"{員工}" 從語言頁回到帳號面板` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：按語言頁左上的返回鈕。 |
| `"{員工}" 沒有登出就{動作}，之後有人再打開櫃檯畫面` | `員工`：字串。<br>`動作`：字串。 | 不支援 | 無 | `使用 fixture`：瀏覽器設定。`頁面操作`：關掉這個分頁（或整個瀏覽器環境，但保留這台裝置的語言紀錄），再開新的分頁前往櫃檯畫面的網址。 |
| `"{員工}" 另開一個新分頁打開櫃檯畫面` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：在同一個瀏覽器環境開新分頁，前往櫃檯畫面的網址。 |
| `"{員工}" 在原本的分頁登出` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：在原本的分頁打開帳號面板、按「登出」並確認。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `登入頁的員工編號欄與密碼欄都是空的` | 無 | 不支援 | 無 | `必查`：兩欄的值都是空字串，瀏覽器也沒有自動填入。 |
| `登入頁的 "{欄位}" 欄顯示 "{內容}"` | `欄位`：字串。<br>`內容`：字串。 | 不支援 | 無 | `必查`：該欄的值照字面相符。 |
| `登入頁的 "{欄位}" 欄裡只有 {上限} 個字` | `欄位`：字串。<br>`上限`：整數。 | 不支援 | 無 | `必查`：該欄值的長度等於上限，多打的字沒有進去。 |
| `密碼欄以明文顯示 "{密碼}"，切換鈕變成 "{按鈕}"` | `密碼`：字串。<br>`按鈕`：字串。 | 不支援 | 無 | `必查`：密碼欄是一般文字欄、看得到該值；切換鈕的名稱相符。 |
| `密碼欄的內容被遮住，切換鈕變成 "{按鈕}"` | `按鈕`：字串。 | 不支援 | 無 | `必查`：密碼欄是密碼型的欄位；切換鈕的名稱相符。 |
| `"{員工}" 登入成功，畫面是 "{頁}"` | `員工`：字串。<br>`頁`：字串。 | 不支援 | 無 | `必查`：畫面是該頁，帳號卡是該員工；這個分頁存了他的登入憑證，拿它讀 `getDeskBoard` 回 200。送出的 `loginId` 與這次輸入的員工編號照字面相同（不轉大小寫、不去空白）。 |
| `這個分頁沒有登入，畫面是 "{頁}"` | `頁`：字串。 | 不支援 | 無 | `必查`：畫面是登入頁；這個分頁的儲存空間沒有任何登入憑證，直接前往總覽看板的網址會被帶回登入頁。 |
| `畫面是 "{頁}"` | `頁`：字串。 | 不支援 | 無 | `必查`：畫面是該頁（登入頁、設定新密碼畫面、總覽看板或待派單頁），以該頁的標題判斷。 |
| `畫面上看不到任何一張單` | 無 | 不支援 | 無 | `必查`：畫面上沒有看板卡片與待派單列；這個分頁沒有送出 `getDeskBoard` 請求。 |
| `登入頁顯示紅字 "{文字}"，密碼欄被清空，員工編號欄保留` | `文字`：字串。 | 不支援 | 無 | `必查`：白卡下方有那一行紅字，不是提示卡；密碼欄是空的，員工編號欄仍是剛才輸入的值，照字面不變；送出的 `loginId` 也是這個值。 |
| `登入頁除了 "{文字}" 沒有其他提示` | `文字`：字串。 | 不支援 | 無 | `必查`：登入頁的提示位置只有這一句；沒有提示卡、沒有對話框，也沒有進入設定新密碼畫面。這次登入請求的回應是 401，內容與同一帳號輸入錯誤密碼時相同。 |
| `登入頁顯示提示卡，標題 "{標題}"、內文 "{內文}"` | `標題`：字串。<br>`內文`：字串。 | 不支援 | 無 | `必查`：白卡下方是一張提示卡（不是一行紅字），標題與內文照字面相符；密碼欄是空的。 |
| `登入頁沒有飯店名稱那一行，其餘文字與欄位照常` | 無 | 不支援 | 無 | `必查`：「登入 TMS 櫃檯」與共用裝置說明之間沒有飯店名稱；兩個欄位、「登入」「忘記密碼？」都在。 |
| `設定新密碼畫面只有 "{欄一}" 與 "{欄二}" 兩個輸入欄` | `欄一`：字串。<br>`欄二`：字串。 | 不支援 | 無 | `必查`：畫面上的輸入欄剛好兩個，名稱相符；沒有要求輸入目前密碼或臨時密碼的欄位。 |
| `設定新密碼畫面的兩個輸入欄都是空的` | 無 | 不支援 | 無 | `必查`：兩欄的值都是空字串。 |
| `規則 "{規則}" 沒有打勾` | `規則`：字串。 | 不支援 | 無 | `必查`：規則清單上那一條是未符合的樣子，其餘三條是符合的樣子。 |
