# 共用外框 DSL（櫃檯 Web）

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

登入後每一頁共用的側欄與工具列、這一版只畫出來但還不能用的入口，以及兩種支援的視窗尺寸與滑鼠、觸控兩種輸入方式。

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `"{員工}" 登入後打開 "{頁}"，側欄是 "{側欄}" 的` | `員工`：字串。<br>`頁`：字串。<br>`側欄`：字串。 | 不支援 | 無 | `頁面操作`：登入並開啟該頁；側欄與該頁的預設不同時按一次「打開側欄」或「收合側欄」。`等待條件`：看板依新的寬度重排完。 |
| `"{員工}" 把看板捲到最右邊` | `員工`：字串。 | 不支援 | 無 | `頁面操作`：把看板本體橫向捲到底（滑鼠用捲動，觸控用滑動）。 |
| `"{員工}" 把視窗調成 {寬} × {高}` | `員工`：字串。<br>`寬`：整數。<br>`高`：整數。 | 不支援 | 無 | `頁面操作`：把網頁顯示區域調成該尺寸。`等待條件`：版面重排完。`回寫資料`：調整前各欄的寬度與各區塊的位置。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `側欄由上到下是標題 "{標題}"、副標 "{副標}"、功能 "{一}"、"{二}"、"{三}"、"{四}" 與帳號卡` | `標題`：字串。<br>`副標`：字串。<br>`一`：字串。<br>`二`：字串。<br>`三`：字串。<br>`四`：字串。 | 不支援 | 無 | `必查`：側欄各項的文字與上下順序相符；副標等於登入回應的 `hotelName`，沒有班次名。 |
| `側欄 "{功能}" 沒有徽章` | `功能`：字串。 | 不支援 | 無 | `必查`：側欄那一項右側沒有徽章（不是顯示 0）；後端目前沒有 `triage` 的單。 |
| `側欄上{有沒有} "{項目}"` | `有沒有`：字串。<br>`項目`：字串。 | 不支援 | 無 | `必查`：`有沒有` 是「有」時側欄看得到那一項；「沒有」時側欄整個找不到那一項。結果與登入回應的 `role` 一致（只有 `manager`、`duty_manager` 有「設定」）。 |
| `側欄的 "{項目}" 底下沒有展開任何項目` | `項目`：字串。 | 不支援 | 無 | `必查`：點過之後那一項底下沒有多出任何子項目。 |
| `畫面是 "{頁}"，頁標題是 "{標題}"` | `頁`：字串。<br>`標題`：字串。 | 不支援 | 無 | `必查`：網址是該頁，工具列的頁標題相符；側欄與工具列還是同一個外框（沒有整頁重新載入）。 |
| `工具列沒有 "{缺少的}"，有 "{有的}"` | `缺少的`：字串。<br>`有的`：字串。 | 不支援 | 無 | `必查`：工具列找不到前者、看得到後者。 |
| `工具列有 "{一}" 與 "{二}"` | `一`：字串。<br>`二`：字串。 | 不支援 | 無 | `必查`：工具列兩者都看得到。 |
| `畫面仍是 "{頁}"，沒有開任何頁面、面板或對話框` | `頁`：字串。 | 不支援 | 無 | `必查`：網址與頁標題不變；沒有新的面板、對話框或提示；被點的入口外觀也沒有變。 |
| `看板的可用寬度比側欄打開時多出側欄的寬度` | 無 | 不支援 | 無 | `必查`：看板本體的寬度比收合前多 300px（側欄的寬度）。 |
| `這個畫面完整顯示在視窗內，沒有整頁的捲軸，也不需要縮放` | 無 | 不支援 | 無 | `必查`：整份文件的寬高不超過視窗，沒有整頁捲軸；這個畫面（面板則是面板本身）的四邊都在視窗內；頁面縮放是 100%；每一顆可以按的東西高度至少 44px。 |
| `看板右緣有按鈕 "{按鈕}"` | `按鈕`：字串。 | 不支援 | 無 | `必查`：看板右緣有那顆按鈕；上面的數字等於目前在視窗右邊看不到的欄數。 |
| `看板右緣沒有「還有 N 個狀態」的按鈕` | 無 | 不支援 | 無 | `必查`：看板右緣找不到這一類按鈕。 |
| `看板往右捲了一欄，看板右緣有按鈕 "{按鈕}"` | `按鈕`：字串。 | 不支援 | 無 | `必查`：看板本體的橫向捲動位置比按之前多一欄的寬度；右緣按鈕的文字相符。 |
| `看得到 "{欄}" 欄` | `欄`：字串。 | 不支援 | 無 | `必查`：那一欄的欄頭完整落在視窗內。 |
| `{欄數} 個欄都看得到，每一欄都比視窗調整前寬` | `欄數`：整數。 | 不支援 | 無 | `必查`：該數量的欄頭都完整落在視窗內；每一欄的寬度都大於調整前記下的寬度。 |
| `看板貼齊內容區的左右兩側，沒有置中留白` | 無 | 不支援 | 無 | `必查`：第一欄的左緣與最後一欄的右緣離內容區邊界都只有固定的邊距（16px）。 |
| `畫面出現整頁的捲軸，捲動後看得到其餘的內容` | 無 | 不支援 | 無 | `必查`：整份文件的寬或高超過視窗、可以捲動；捲到底後原本看不到的區塊落在視窗內。 |
| `側欄、工具列、數量卡與看板的排法與視窗調整前相同` | 無 | 不支援 | 無 | `必查`：這幾個區塊的相對位置與尺寸和調整前記下的相同，沒有換成另一套版面（例如側欄變成抽屜、數量卡換行）。 |
| `這個畫面上每一項內容與每一顆可以按的東西，不用游標移上去就看得到、按得到` | 無 | 不支援 | 無 | `必查`：在沒有任何游標停留的情況下，把這個畫面上看得到的文字與可按的東西記下來；再對每一個元素模擬游標停留，畫面上沒有多出任何新的文字或可按的東西。 |
