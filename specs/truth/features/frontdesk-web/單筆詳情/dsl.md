# 單筆詳情 DSL（櫃檯 Web）

這個模組的專屬句型。跨模組共用句型見 [`../dsl.md`](../dsl.md)。

單筆詳情面板：住客來電時讀一句現在的狀況照著回答；待派單的單可以直接在這裡派或回答。內容讀 `readDeskTask`，歷程的每一句話由畫面依事件種類與內容組出來；面板開著時收到這張單的即時訊號就重讀。

**工務單照片**：工務單的面板在「內容」與歷程之間有「報修照片」「完修照片」兩排縮圖，照片編號來自 `DeskTaskDetail.repair.photos` 與 `repair.completionPhotos`，沒有照片的那一排不出現，不是工務單的面板沒有這兩排。畫面以 `fetch` 帶 `Authorization` 標頭呼叫 `getRepairPhotoContent` 拿到照片位元組，轉成 `blob:` 網址給 `<img>`，面板關掉或換單時釋放；網址裡不帶登入憑證。點縮圖打開看大圖，只在同一排裡切換；讀不到的照片（例如這版之前的假照片）在縮圖與大圖都顯示「照片無法顯示」，其他照片照常。後端資料準備：照片由 `BackendChannel` 以報修人（報修照片）或處理人（完修照片）身分呼叫 `createRepairPhoto` 與 `uploadRepairPhotoContent` 建立，每張內容是不同的合法 JPEG，再綁到這張單；「舊版的假照片」是把該照片的 `storage_ref` 改成 `upload:{photoId}`。

## Given 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `"{房號}" 的工務單有 {報修張數} 張報修照片、{完修張數} 張完修照片` | `房號`：字串；本案例 `全館有以下的單：` 裡那間房唯一的修繕單。<br>`報修張數`：整數 0 至 3。<br>`完修張數`：整數 0 至 3。 | 不支援 | 無 | `Arrange 來源`：`BackendChannel` 先刪掉這張單已綁的照片列，再以報修人身分建立並上傳報修照片、以處理人身分建立並上傳完修照片（每張內容是不同的合法 JPEG），最後把它們綁到這張單；完修照片的上傳時間晚於這張單最近一次驗收不通過，算在這一輪。`等待條件`：`readDeskTask` 的 `repair.photos` 與 `repair.completionPhotos` 張數相符。 |
| `"{房號}" 的工務單第 {第幾張} 張報修照片是舊版的假照片` | `房號`：字串。<br>`第幾張`：整數；依 `repair.photos` 的順序，從 1 起算。 | 不支援 | 無 | `Arrange 來源`：`BackendChannel` 把那張照片的 `storage_ref` 改成 `upload:{photoId}`，`status` 仍是 uploaded。`等待條件`：以後端讀那張照片回 404。 |
| `"{員工}" 開著 "{房號}" 詳情面板 "{區塊}" 第 {第幾張} 張照片的大圖` | `員工`：字串。<br>`房號`：字串。<br>`區塊`：字串；報修照片、完修照片。<br>`第幾張`：整數。 | 不支援 | 無 | `Arrange 來源`：同 `"{員工}" 開著 "{房號}" 的詳情面板`。`頁面操作`：點該排的第幾張縮圖。`等待條件`：看大圖出現，圖片載入完成。 |
| `"{員工}" 剛在 "{頁}" 把 "{房號}" 派給 "{部門}" 又按了「復原」` | `員工`：字串。<br>`頁`：字串。<br>`房號`：字串。<br>`部門`：字串。 | 不支援 | 無 | `Arrange 來源`：以該員工登入並開啟該頁。`頁面操作`：打開該房的詳情面板按「派給{部門}」，在浮條上按「復原」，再關閉面板。`等待條件`：復原成功、浮條消失。 |

## When 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `"{員工}" 點詳情面板 "{區塊}" 的第 {第幾張} 張縮圖` | `員工`：字串。<br>`區塊`：字串；報修照片、完修照片，或該語言的區塊標題。<br>`第幾張`：整數。 | 不支援 | 無 | `頁面操作`：在詳情面板該排點第幾張縮圖（滑鼠點或觸控點，依瀏覽器設定）。`等待條件`：看大圖出現。 |
| `"{員工}" 在看大圖按 "{按鈕}"` | `員工`：字串。<br>`按鈕`：字串；上一張、下一張、關閉。 | 不支援 | 無 | `頁面操作`：按看大圖上該名稱的按鈕。`等待條件`：大圖換成另一張並載入完成，或看大圖關閉。 |

## Then 句型

| DSL 句型 | Gherkin 參數 | Data Table 參數 | 預設參數 | 櫃檯 Web 實作語意（Playwright） |
| --- | --- | --- | --- | --- |
| `詳情面板貼齊畫面右側` | 無 | 不支援 | 無 | `必查`：面板的右緣等於視窗右緣、佔滿高度；看板讓出面板的寬度。 |
| `詳情面板由上到下依序是 "{關閉}" 與單號、房號 "{房號}" 與狀態標籤、標題 "{標題}"、"{那一行}"、狀態訊息卡、"{內容標題}"、"{歷程標題}"` | `關閉`：字串。<br>`房號`：字串。<br>`標題`：字串。<br>`那一行`：字串。<br>`內容標題`：字串。<br>`歷程標題`：字串。 | 不支援 | 無 | `必查`：各區塊都在、上下順序相符，引號內的文字照字面相符。 |
| `詳情面板的單號是 "{單號}"` | `單號`：字串。 | 不支援 | 無 | `必查`：關閉列中間的單號相符，面板上只有這一個單號；等於後端的 `displayNo`。 |
| `詳情面板的「內容」如下：` | 無 | 支援：`列名`（必填，字串）、`內容`（必填，字串） | 無 | `必查`：「內容」區塊的列數、列名、順序與每一列的值都與表格相同。 |
| `詳情面板上沒有住客人數` | 無 | 不支援 | 無 | `必查`：面板上沒有「人」「位」這類人數字樣；「住客」列只有姓名與入住、退房日期。 |
| `詳情面板標題下那一行是 "{文字}"` | `文字`：字串。 | 不支援 | 無 | `必查`：標題下的灰字照字面相符。 |
| `詳情面板的標題是 "{標題}"` | `標題`：字串。 | 不支援 | 無 | `必查`：面板的標題照字面相符（含「」）。 |
| `詳情面板的原文列是 "{文字}"` | `文字`：字串。 | 不支援 | 無 | `必查`：標題下的原文列照字面相符。 |
| `詳情面板沒有原文列` | 無 | 不支援 | 無 | `必查`：面板上沒有「原文：」開頭的那一列。 |
| `詳情面板的「清潔 SOP」區塊：{有沒有}` | `有沒有`：字串。 | 不支援 | 無 | `必查`：`有沒有` 是「有」時面板有「清潔 SOP」區塊；「沒有」時找不到。 |
| `詳情面板的清潔 SOP 顯示 "{文字}" 與進度條` | `文字`：字串。 | 不支援 | 無 | `必查`：「清潔 SOP」區塊右側的文字相符，下面有進度條，比例等於已做項數除以總項數。 |
| `詳情面板上沒有急件標記` | 無 | 不支援 | 無 | `必查`：面板上沒有「急件」字樣或急件圖示。 |
| `詳情面板的狀態標籤是 "{標籤}"` | `標籤`：字串。 | 不支援 | 無 | `必查`：房號右側的狀態標籤文字相符；它由後端既有的狀態值推得，後端的 `state` 仍在十個值之內。 |
| `詳情面板的狀態訊息卡標題是 "{標題}"，說明是 "{說明}"` | `標題`：字串。<br>`說明`：字串。 | 不支援 | 無 | `必查`：狀態訊息卡的標題與說明照字面相符；裡面的人名、時刻、分鐘數與後端這張單的資料一致。 |
| `詳情面板的狀態訊息卡只有標題 "{標題}"，沒有說明` | `標題`：字串。 | 不支援 | 無 | `必查`：狀態訊息卡的標題照字面相符，卡上沒有第二行。 |
| `詳情面板沒有狀態訊息卡` | 無 | 不支援 | 無 | `必查`：標題那一塊下面直接是「內容」，中間沒有狀態訊息卡。 |
| `詳情面板的狀態訊息卡沒有 "{文字}"` | `文字`：字串。 | 不支援 | 無 | `必查`：狀態訊息卡的文字不含該字。 |
| `詳情面板的狀態訊息卡寫出經手的主管是 "{主管}"` | `主管`：字串。 | 不支援 | 無 | `必查`：狀態訊息卡的說明含該主管的姓名；等於後端記的延後者或取消者。 |
| `詳情面板的歷程標題是 "{標題}"` | `標題`：字串。 | 不支援 | 無 | `必查`：歷程區塊的標題照字面相符。 |
| `詳情面板的歷程由舊到新包含以下各筆：` | 無 | 支援：`句子`（必填，字串）、`時間`（必填，字串 `HH:mm`）、`操作者`（必填，字串） | 無 | `必查`：歷程由上到下（舊到新）的筆數、句子、時間與操作者都與表格相同；與後端 `readDeskTask` 的 `timeline` 一一對應。 |
| `詳情面板的歷程最新一筆的時間與操作者寫的是 "{文字}"` | `文字`：字串。 | 不支援 | 無 | `必查`：歷程最下面那一筆句子下方的灰字照字面相符。 |
| `詳情面板的歷程沒有 "{句子}"` | `句子`：字串。 | 不支援 | 無 | `必查`：歷程的每一筆都不是該句子。 |
| `詳情面板的歷程比原本多一筆 "{句子}"，原本的各筆都沒有變` | `句子`：字串。 | 不支援 | 無 | `必查`：歷程比 When 之前記下的多一筆，在最下面，句子相符；之前每一筆的句子、時間、操作者與順序都沒有變。 |
| `詳情面板底部的派單區依序是 "{一}"、"{二}"、"{三}" 三格` | `一`：字串。<br>`二`：字串。<br>`三`：字串。 | 不支援 | 無 | `必查`：面板底部固定的「派單」區剛好三格、等寬，名稱與順序相符。 |
| `派單區的格子裡沒有待接數、在班人數與 "{文字}" 小標` | `文字`：字串。 | 不支援 | 無 | `必查`：三格裡只有按鈕文字，沒有任何數字、「在班」字樣或該文字。 |
| `詳情面板沒有「單據管理」動作列` | 無 | 不支援 | 無 | `必查`：面板底部沒有「取消」「延後…」「指派…」「轉派…」任何一顆。 |
| `詳情面板沒有派單區，也沒有 "{按鈕}"` | `按鈕`：字串。 | 不支援 | 無 | `必查`：面板底部沒有「派給房務」「派給工務」，整個面板也找不到該按鈕。 |
| `詳情面板的「單據管理」動作列是：{動作列}` | `動作列`：字串。 | 不支援 | 無 | `必查`：`動作列` 是以 `、` 分隔的按鈕名稱時，面板底部剛好是這幾顆、順序相符；寫「整列不出現」時底部沒有這一列。結果與登入回應的 `role` 及這張單的狀態一致。 |
| `詳情面板的 "{區塊}" 有 {張數} 張縮圖，依序是這張單的照片` | `區塊`：字串；報修照片、完修照片。<br>`張數`：整數。 | 不支援 | 無 | `必查`：該排標題文字相符、縮圖剛好張數張；每張 `<img>` 已載入（`naturalWidth` 大於 0）、`src` 以 `blob:` 開頭；第 n 張的位元組等於後端 `readDeskTask` 對應陣列第 n 個 id 以 `getRepairPhotoContent` 讀到的位元組。`不該發生`：頁面送出的照片請求網址不含登入憑證，憑證只在 `Authorization` 標頭。 |
| `詳情面板的照片區塊排在 "{前}" 之後、"{後}" 之前` | `前`：字串。<br>`後`：字串。 | 不支援 | 無 | `必查`：兩排照片都在標題為 `前` 的區塊下方、標題為 `後` 的區塊上方，報修照片在完修照片上面。 |
| `詳情面板沒有 "{區塊}" 這一排` | `區塊`：字串。 | 不支援 | 無 | `必查`：面板上找不到該標題，也沒有屬於該排的縮圖；後端對應的陣列是空的。 |
| `詳情面板沒有照片` | 無 | 不支援 | 無 | `必查`：面板上沒有「報修照片」「完修照片」標題，也沒有任何照片縮圖；頁面沒有送出任何 `getRepairPhotoContent` 請求。 |
| `看大圖顯示 "{區塊}" 的第 {第幾張} 張，標示 "{計數}"` | `區塊`：字串。<br>`第幾張`：整數。<br>`計數`：字串；`第幾張 / 總張數`。 | 不支援 | 無 | `必查`：看大圖蓋在畫面上，標題是該排名稱，計數照字面相符；顯示的圖片位元組等於該排第幾張照片從後端讀到的位元組。 |
| `詳情面板 "{區塊}" 的第 {第幾張} 張顯示 "{文字}"` | `區塊`：字串；可以是該語言的區塊標題。<br>`第幾張`：整數。<br>`文字`：字串。 | 不支援 | 無 | `必查`：那一格是灰底，裡面的文字照字面相符，沒有載入成功的圖片。 |
| `詳情面板 "{區塊}" 的第 {第幾張} 張是這張單的照片` | `區塊`：字串。<br>`第幾張`：整數。 | 不支援 | 無 | `必查`：那一格的圖片已載入，位元組等於該排第幾張照片從後端讀到的位元組。 |
| `詳情面板的照片區塊標題依序是 "{報修}"、"{完修}"` | `報修`：字串。<br>`完修`：字串。 | 不支援 | 無 | `必查`：兩排的標題照字面相符、報修在上；是目前介面語言的版本。 |
| `詳情面板的照片縮圖都在面板寬度內，每張至少 44 × 44` | 無 | 不支援 | 無 | `必查`：每張縮圖的外框都在詳情面板的左右邊界內，面板沒有橫向捲軸；每張縮圖可點的範圍至少 44 × 44。 |
